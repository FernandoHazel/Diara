Conceptos de HTML y CSS

¿Qué es HTML?

HTML no es un lenguaje de programación; es un lenguaje de marcado que define la estructura del contenido de una página web. HTML significa HyperText Markup Language o lenguaje de marcado de hypertexto.

Tags

Un tag es solo la etiqueta escrita entre "< >", por ejemplo: "<p>", "<h1>" etc.

Elementos

Un elemento es todo el conjunto.

  1. Tiene etiqueta de apertura "<>"
  2. Contenido como: "Hola mundo"
  3. Etiqueta de cierre "</>"
Por ejemplo: <h1>Hola Mundo</h1>

headings

Los headings son elementos para definir títulos, subtítulos etc hasta en 6 niveles que van desde h1 hasta h6.

Atributos

Los atributos son formas de configurar el elemento, no es contenido que aparezca en pantalla,
se pueden usar para indicar estilos, definir enlaces o añadir alternativas de accesibilidad entre otras cosas.

Por ejemplo:
Para el elemento <a href="https://google.com">Ir a Google</a>
href="https://google.com" es un atributo y el resultado sería el siguiente:
Ir a Google

Párrafos

Son elementos que se utilizan para escribir párrafos de texto y se escriben así:
<p>Contenido del párrafo</p>

Anidando elementos

Se pueden incluir elementos dentro de otros elementos, por ejemplo, para resaltar una palabra en negrita se puede escribir un texto dentro de un <p></p> y añadir una etiqueta <strong></strong> para envolver la palabra que se quiere resaltar, por ejemplo:
<p>Este es un texto de ejemplo con <strong>esta fráse resaltada</strong></p>

El resultado sería el siguiente:
Este es un texto de ejemplo con esta frase resaltada.

Anchors

Anchors o Anclas en español, son los enlaces que hacen que la web sea la web, se representan con el tag <a>, tienen como atributo un href que define el enlace al que va a llevar y en el contenido puede tener un texto cualquiera.

Comentarios

Los comentarios son una especie de etiquetas que los programadores insertan para recordarse a ellos y a otros programadores qué hace su código, los comentarios NO son código ejecutable lo que significa que no afectan al comportamiento del sitio.
Por ejemplo:

Las entidades nos ayudan a incluir caracteres especiales en HTML. En HTML, los caracteres <, >, ", ', & son caracteres especiales.
Son partes de la sintaxis HTML en sí. Entonces se utilizan referencias que empiezan con "&" y terminan con ";" La lista completa de entidades se puede encontrar en la lista de entidades

Semantic HTML

Es fácil confundir Text Formatting con Semantic HTML pero no son lo mismo:

  • Text Formatting se enfoca en cómo destacar o presentar texto.
  • Semantic HTMLse enfoca en describir el significado y propósito del contenido.

Los motores de busqueda que indizan la página se basan en los tags para saber qué palabras clave son más importantes e influyen en la puntuación de búsqueda de la página, de lo contrario el sitio tendrá bajo rendimiento en buscadores (SEO).
Por ejemplo esto es text formatting: <p>Aprende <strong>HTML</strong> y <em>CSS</em>.</p>

Y esto es semantic HTML: 

        
        <header>
        <h1>Mi Blog</h1>

        <nav>
            Menú de navegación
        </nav>

        <main>
            Contenido principal
        </main>

        <footer>
            Derechos reservados
        </footer>

Forms

Los formularios web son uno de los principales puntos de interacción entre un usuario y un sitio web o aplicación.
Los formularios permiten a los usuarios la introducción de datos, que generalmente se envían a un servidor web para su procesamiento y almacenamiento.

El HTML de un formulario web está compuesto por uno o más controles de formulario (a veces llamados widgets).
Los controles pueden ser campos de texto de una o varias líneas, cajas desplegables, botones, casillas de verificación o botones de opción, y se crean principalmente con el elemento <input>.

Los controles de formulario también se pueden programar para forzar la introducción de formatos o valores específicos (validación de formulario).

Se puede ver más sobre los formularios en este enlace: forms

Box Model

El modelo de caja de CSS es un concepto fundamental que describe cómo se representan los elementos HTML en la página web.
Cada elemento se representa como una caja rectangular que consta de cuatro áreas: el contenido, el relleno (padding), el borde (border) y el margen (margin).
El modelo de caja de CSS
Block_and_inline_layout

Estas propiedades de pueden definir usando las palabras: padding, margin, border para añadir espacio al rededor de los elementos,
sin embargo también se puede añadir espacio a un sólo lado añadiendo la palabra left, right, top o bottom después de la propiedad, por ejemplo: padding-left, margin-top etc.

Es importante saber que existen dos modelos el estándar y el modelo de caja alternativo, el estándar es el que se usa por defecto y el modelo de caja alternativo se activa usando la propiedad box-sizing: border-box;
La diferencia es que en el modelo estándar el tamaño total de un elemento se calcula sumando el tamaño del contenido, el relleno, el borde y el margen, mientras que en el modelo de caja alternativo el tamaño total de un elemento se calcula sólo con el tamaño del contenido y el borde,
es decir, el relleno y el margen no afectan al tamaño total del elemento lo cuál lo hace más predecible.

Box sizing

En el modelo de caja hay dos formas de calcular el tamaño total de un elemento, el modelo de caja estándar y el modelo de caja alternativo.
Para cambiar entre modelos se utiliza la propiedad box-sizing, que puede tomar los siguientes valores: content-box para el modelo de caja estándar y border-box para el modelo de caja alternativo.

  1. content-box, es el comportamiento CSS por defecto para el tamaño de la caja (box-sizing). Si se define el ancho de un elemento en 100 pixeles, la caja del contenido del elemento tendrá 100 pixeles de ancho, y el ancho de cualquier borde o relleno ser añadirá al ancho final desplegado.
  2. border-box le dice al navegador tomar en cuenta para cualquier valor que se especifique de borde o de relleno para el ancho o alto de un elemento. Es decir, si se define un elemento con un ancho de 100 pixeles. Esos 100 pixeles incluíran cualquier borde o relleno que se añadan, y la caja de contenido se encogerá para absorber ese ancho extra. Esto típicamente hace mucho más fácil dimensionar elementos.

Display

La propiedad CSS display especifica si un elemento es tratado como block or inline element y el diseño usado por sus hijos, como flow layout(Diseño de Flujo), grid(Cuadricula) o flex(Flexible).
Formalmente la propiedad display establece los tipos de visualización interna y externa de un elemento. La tipo externa establece la participacion de un elemento en flow layout; la tipo interna establece el layout(Diseño) de los hijos.
Algunos valores de display estan totalmente definidos con sus especificaciones propias; por ejemplo el detalle de que pasa cuando display: flex es declarado y definido en la especificacion de Modelo Flexible de Caja(Flexible Box Model specification) de CSS.

Position

La propiedad CSS position especifica el tipo de posicionamiento de un elemento.
Esta propiedad es muy importante porque controla cómo se posicionan los elementos en la página web, y es fundamental para crear diseños complejos.
Position:

  • static: Es el valor por defecto, los elementos se posicionan de acuerdo al flujo normal del documento.
  • relative: El elemento se posiciona de acuerdo al flujo normal del documento, pero luego se desplaza respecto a su posición original utilizando las propiedades top, right, bottom y left.
  • absolute: El elemento se posiciona respecto a su primer ancestro posicionado (que no sea static), o respecto al viewport si no hay ningún ancestro posicionado. Se puede desplazar utilizando las propiedades top, right, bottom y left.
  • fixed: El elemento se posiciona respecto al viewport, lo que significa que siempre estará en la misma posición incluso cuando se haga scroll. Se puede desplazar utilizando las propiedades top, right, bottom y left.
  • sticky: El elemento se comporta como relative hasta que su contenedor alcance un punto específico en el viewport, momento en el cual se comporta como fixed.

Visibility

Los valores de la propiedad visibility son:

Flexbox

Flexbox es un método de diseño de página unidimensional para compaginar elementos en filas o columnas. Los elementos de contenido se ensanchan para rellenar el espacio adicional y se encogen para caber en espacios más pequeños.
Es muy útil cuando se quiere hacer cosas como:
Flexbox

  • Centrar verticalmente un bloque de contenido dentro de su elemento padre.
  • Hacer que todos los elementos secundarios de un contenedor ocupen una cantidad igual del ancho/alto disponible, independientemente del ancho/alto que haya disponible.
  • Hacer que todas las columnas en una compaginación en columnas múltiples adopten la misma altura incluso si contienen cantidades diferentes de contenido.
Lo primero que se debe de hacer es añadir la propiedad display: flex; al elemento padre de los elementos que queremos ordenar.
Esto hace que ese elemento se convierta en un contenedor flex y sus hijos en elementos flexibles. Por ejemplo, una sección que contiene varios artículos: 
            
                
                    section {
                        display: flex;
                    }
Nota: al hacer esto el contenedor pasa a comportarse como un elemento en bloque mientras que sus hijos son flexibles. Para hacer que el padre se comporte como elemento en línea se puede usar display: inline-flex;

Para crear un grid se debe añadir la siguiente propiedad al contenedor de los elementos display: grid; o display: inline-grid CSS Grid Course

Algunos de los conceptos más útiles de CSS Grid son los siguientes:

  • grid-template-colums permite definir cuántas columntas y de qué medida habrá en la cuadrícula.
  • grid-template-rows permite definir cuántas filas y de qué tamaño habrá en la cuadrícula.
  • grid-template-areas permite definir cuántas columnas o filas abarcará un mismo elemento.
  • repeat() es una función que permite repetir las columnas o filas con menos código.
  • fr es una medida que representa cantidad de fracciones que debe de abarcar un elemento en alto o ancho.
  • grid-auto-rows y grid-auto-columns. automatizan grid-template-colums y grid-template-rows para que la cuadrícula genere la cantidad de filas o columnas que crea necesarias usando la misma medida.
  • minmax() es una función que ayuda a definir una medida mínima y máxima para los elementos de modo que puedan adaptar su tamaño al espacio disponible en la pantalla. Una combinación útil es minmax(100px, auto) para que el elemento no se pueda achicar demasiado pero si expandirse según se requiera.
  • grid-column-start, grid-column-end, grid-row-start, grid-row-end sirven para decirle a un elemento en qué linea de la cuadrícula debe comenzar y terminar.
  • grid-column-gap, grid-row-gap, grid-gap se utilizan para crear espacio entre las celdas de la cuadrícula para que los elementos no queden pegados unos con otros.
  • Dentro de una misma celda se pueden poner varios elementos uno sobre otro usando z-index, por ejemplo, para poner un texto con una imagen o video de fondo.

Flexbox vs Grid

Tanto Flexbox como Grid nos ayudan a crear layouts responsivos, así qué ¿Cuándo sabemos cuál deberíamos usar? Flexbox vs Grid

  • Flexbox se enfoca más en los elementos hijos, haciendo que normalmente haya que añadirle reglas especiales a cada uno.
  • Grid se enfoca más en el contenedor padre, trata de definir la estructura todo en uno.
Cuando no estemos seguros de cuál usar hay que preguntarnos ¿Qué es más importante? ¿Una distribución uniforme enfocada en el padre? Hay que elegir Grid ¿O una distribución flexible en la que los hijos puedan sobreponerse a la distribución del padre? Entonces sería mejor elegir Flexbox.

Transform functions

Transforms

La propiedad CSS transform te permite modificar el espacio de coordenadas del modelo de formato visual CSS. Usándola, los elementos pueden ser trasladados, rotados, escalados o sesgados de acuerdo a los valores establecidos.

transform: matrix(2, 1, 1, 1, 1, 1);
Aplica una transformación usando una matriz. Es la forma más avanzada de transformar un elemento porque combina escalado, inclinación y traslación en una sola instrucción. Los primeros cuatro valores controlan la forma y tamaño del elemento, mientras que los dos últimos lo desplazan en los ejes X e Y.

transform: translate(120px, 10%);
Mueve el elemento sin cambiar su tamaño ni su forma. En este caso se desplaza 120 píxeles hacia la derecha y un 10% hacia abajo respecto a su posición original.

transform: scale(2, 0.5);
Cambia el tamaño del elemento. El valor 2 duplica su ancho y el valor 0.5 reduce su altura a la mitad.

transform: rotate(0.5turn);
Rota el elemento. La unidad turn representa una vuelta completa, por lo que 0.5turn equivale a media vuelta (180 grados).

transform: skew(30deg, 20deg);
Inclina el elemento. El primer valor inclina 30 grados sobre el eje X y el segundo valor 20 grados sobre el eje Y, produciendo un efecto similar a empujar los lados de una figura.

transform: scale(0.5) translate(100%, 100%);
Combina varias transformaciones. Primero reduce el elemento al 50% de su tamaño original y después lo desplaza un 100% de su propio ancho hacia la derecha y un 100% de su propia altura hacia abajo.

La diferencia entre una transición y una animación es que la transición sólo interpola entre dos valores, por ejemplo, cambiar el tamaño de una fuente de 12px a 24px en un segundo. pero las animaciones permiten definir varios estados mediante keyframes, por ejemplo:

                    }

                    A la mitad de la animación crece 150%
                    50% {
                        transform: scale(1.5);
                    }

                    Al final de la animación regresa a su tamaño normal
                    100% {
                        transform: scale(1);
                    }
                }

                En este caso se le aplica la animación a las imagenes, en este caso tomará 2 segundos y se repite indefinidamente

Math Functions

CSS moderno incluye varias funciones matemáticas que permiten hacer cálculos directamente en las hojas de estilo sin necesidad de JavaScript.

  • calc()Es la más utilizada. Permite sumar, restar, multiplicar y dividir valores. Ejemplo: width: calc(100% - 40px); Si el contenedor padre mide 800px, 800px - 40px = 760px. También se pueden mezclar unidades. Ejemplo font-size: calc(1rem + 1vw);
  • min()Toma el valor más pequeño de una lista width: min(600px, 90%);significa que usa 600px si el 90% es mayor que 600px o usa el 90% si es menor que 600px.
  • max()Toma el valor más grande: width: max(300px, 50%); garantiza que el valor nunca es menor a 300px
  • clamp()Una de las más utilizadas actualmente, la sintaxis es: clamp(mínimo, ideal, máximo) ejemplo: font-size: clamp(1rem, 4vw, 3rem); significa que nunca es menor de 1rem intenta usar 4vw y nunca es más de 3rem
