Conceptos de HTML y CSS

¿Qué es HTML?

HTML no es un lenguaje de programación; es un lenguaje de marcado que define la estructura del contenido de una página web. HTML significa HyperText Markup Language o lenguaje de marcado de hypertexto.

Tags

Un tag es solo la etiqueta escrita entre "< >", por ejemplo: "<p>", "<h1>" etc.

Elementos

Un elemento es todo el conjunto.

  1. Tiene etiqueta de apertura "<>"
  2. Contenido como: "Hola mundo"
  3. Etiqueta de cierre "</>"
Por ejemplo: <h1>Hola Mundo</h1>

headings

Los headings son elementos para definir títulos, subtítulos etc hasta en 6 niveles que van desde h1 hasta h6.

Atributos

Los atributos son formas de configurar el elemento, no es contenido que aparezca en pantalla,
se pueden usar para indicar estilos, definir enlaces o añadir alternativas de accesibilidad entre otras cosas.

Por ejemplo:
Para el elemento <a href="https://google.com">Ir a Google</a>
href="https://google.com" es un atributo y el resultado sería el siguiente:
Ir a Google

Párrafos

Son elementos que se utilizan para escribir párrafos de texto y se escriben así:
<p>Contenido del párrafo</p>

Anidando elementos

Se pueden incluir elementos dentro de otros elementos, por ejemplo, para resaltar una palabra en negrita se puede escribir un texto dentro de un <p></p> y añadir una etiqueta <strong></strong> para envolver la palabra que se quiere resaltar, por ejemplo:
<p>Este es un texto de ejemplo con <strong>esta fráse resaltada</strong></p>

El resultado sería el siguiente:
Este es un texto de ejemplo con esta frase resaltada.

Listas

Tambien existen las listas, dentro de HTML hay dos tipos; ordenadas y desordenadas, las ordenadas se representan con <ol> que significa "ordered list" y <ul> que significa "unrdered list" ambas contienen elementos <li> que significan "list item"
Ejemplo:

Esta es una lista desordenada

  • tecnólogos
  • pensadores
  • constructores

Esta es una lista ordenada

  1. tecnólogos
  2. pensadores
  3. constructores

Anchors

Anchors o Anclas en español, son los enlaces que hacen que la web sea la web, se representan con el tag <a>, tienen como atributo un href que define el enlace al que va a llevar y en el contenido puede tener un texto cualquiera.
Ejemplo:
<a href="https://www.mozilla.org/es-AR/about/manifesto/">Manifesto Mozilla</a>
Se ve de la siguiente forma:
Manifesto Mozilla

Comentarios

Los comentarios son una especie de etiquetas que los programadores insertan para recordarse a ellos y a otros programadores qué hace su código, los comentarios NO son código ejecutable lo que significa que no afectan al comportamiento del sitio.
Por ejemplo:
<!-- Esto de aquí es un comentario -->

Entidades

Las entidades nos ayudan a incluir caracteres especiales en HTML. En HTML, los caracteres <, >, ", ', & son caracteres especiales.
Son partes de la sintaxis HTML en sí. Entonces se utilizan referencias que empiezan con "&" y terminan con ";" La lista completa de entidades se puede encontrar en la lista de entidades

Favicon

Es la imagen o el logo del sitio que aparece junto al título del documento, es un archivo .ico que se inserta en las cabeceras de la siguiente formabr <link rel="icon" href="../images/sol.ico">

File Paths

Es la manera de encontrar archivos dentro del almacenamiento del sistema. Por ejemplo para poner una imagen es necesario
especificar en el atributo "src" la ruta al recurso en los archivos, por lo general los recursos se almacenan en carpetas
dentro del proyecto como en una carpeta "resources", "images", "video" etc.

Por ejemplo, para poner el logo de firefox usamos el elemento img y especificamos la ruta en el atributo "src". 

        
            
                <img src="images/firefox-icon.png" alt="Logo de Firefox" />

Semantic HTML

Es fácil confundir Text Formatting con Semantic HTML pero no son lo mismo:

  • Text Formatting se enfoca en cómo destacar o presentar texto.
  • Semantic HTMLse enfoca en describir el significado y propósito del contenido.

Los motores de busqueda que indizan la página se basan en los tags para saber qué palabras clave son más importantes e influyen en la puntuación de búsqueda de la página, de lo contrario el sitio tendrá bajo rendimiento en buscadores (SEO).
Por ejemplo esto es text formatting: <p>Aprende <strong>HTML</strong> y <em>CSS</em>.</p>

Y esto es semantic HTML: 

        
        <header>
        <h1>Mi Blog</h1>
        </header>

        <nav>
            Menú de navegación
        </nav>

        <main>
            Contenido principal
        </main>

        <footer>
            Derechos reservados
        </footer>

Algunos ejemplos de Semantic HTML: 

        | Etiqueta    | Significado                |
        | ----------- | -------------------------- |
        | `<header>`  | Encabezado                 |
        | `<nav>`     | Navegación                 |
        | `<main>`    | Contenido principal        |
        | `<section>` | Sección temática           |
        | `<article>` | Artículo independiente     |
        | `<aside>`   | Información complementaria |

iframe

El elemento HTML <iframe> (de inline frame) representa un contexto de navegación anidado, el cual permite incrustrar otra página HTML en la página actual.
Nota: Al permitir que se muestre contenido de otra web es necesario tener algunas considereaciones de seguridad y delimitar qué se le permite al iframe y qué no.
para más detalles se puede consultar iframe

El siguiente es un ejemplo de un iframe mostrando otra página web, concretamente fhazel.com.mx
Código: 

        
        <iframe
        src="https://fhazel.com.mx"
        title="iframe Example 1"
        width="400"
        height="300">
        <p>Your browser does not support iframes.</p>
        </iframe>

Forms

Los formularios web son uno de los principales puntos de interacción entre un usuario y un sitio web o aplicación.
Los formularios permiten a los usuarios la introducción de datos, que generalmente se envían a un servidor web para su procesamiento y almacenamiento.

El HTML de un formulario web está compuesto por uno o más controles de formulario (a veces llamados widgets).
Los controles pueden ser campos de texto de una o varias líneas, cajas desplegables, botones, casillas de verificación o botones de opción, y se crean principalmente con el elemento <input>.

Los controles de formulario también se pueden programar para forzar la introducción de formatos o valores específicos (validación de formulario).

Se puede ver más sobre los formularios en este enlace: forms 

        Este es un ejemplo de un formulario simple:
        
            
                <form action="/my-handling-form-page" method="post"></form>

Ten en cuenta el uso del atributo for en todos los elementos <label>, que toma como valor el id del control de formulario con el que está asociado; así es como asocias un formulario con su etiqueta.
En el elemento <input>, el atributo más importante es type. Este atributo es muy importante porque define la forma en que el elemento <input> aparece y se comporta.
El elemento <button> también acepta un atributo de type, que a su vez acepta uno de estos tres valores: submit, reset o button.

Así es como quedó el código al final: 

        
            
                <form action="/my-handling-form-page" method="post">
                    <ul>
                        <li>
                            <label for="name">Nombre:</label>
                            <input type="text" id="name" name="user_name" value="nombre"/>
                        </li>
                        <li>
                            <label for="mail">Correo electrónico:</label>
                            <input type="email" id="mail" name="user_mail" value="ejemplo@gmail.com"/>
                        </li>
                        <li>
                            <label for="msg">Mensaje:</label>
                            <textarea id="msg" name="user_message">Este es un mensaje de ejemplo</textarea>
                        </li>
                    </ul>
                    <button type="submit">Envíe su mensaje</button>
                </form>

Classes

Las clases son atributos que se pueden añadir a cualquier etiqueta HTML y ayudan a CSS a identificar dichos elementos y aplicarles estilo.
por ejemplo, podemos tener la clase "destacado" y aplicarla tanto a un div, un span o un párrafo, después en el archivo .css se definen los estilos
para la clase "destacado" y estos estilos se aplicarán a todos los elementos que implementen dicha clase.

Ejemplo de html: 

        
            
                <p class="rojo">Primer párrafo</p>
                <p>Segundo párrafo</p>
                <p class="rojo">Tercer párrafo</p>

Y en el archivo CSS: 

        
            
                .rojo {
                    color: red;
                }

Resultado:

Primer párrafo

Segundo párrafo

Tercer párrafo

La clase funciona como una categoría o grupo que comparte estilos, por ejemplo la clase "error" podría definir elementos que son erroress
y por lo tanto comparten estilos como tener un mismo tipo de fuente y texto de color rojo.
Por eso es buena práctica usar nombres descriptivos para nombrar a nuestras clases.

CSS Anatomy

CSS significa Cascading Style Sheets, y es un lenguaje para aplicar estilos a archivos HTML, se compone de selectores, propiedades y valores.
Por ejemplo: 

        
            
                body {
                    background-color: lightgray;
                }

Classes

Las clases sirven para crear categorías de estilo, estas clases se pueden aplicar a casi cualquier etiqueta de HTML.
Se declaran en el archivo CSS con un "." antes del nombre de la clase. Ejemplo: 

        
            
                .error {
                    color: red;
                    text-decoration: underline;
                }

CSS Comments

Son notas que se añaden en el archivo CSS y no son código ejecutable. Se declaran usando "/**/" y escribiendo en medio de los asteriscos.
Por ejemplo: 

        
            
                /* Los comentarios son notas que se añaden en el archivo CSS y no son código ejecutable */

Colors

Un mismo color se puede especificar de muchas formas por ejemplo:

  1. El nombre del color si es que aparece entre las opciones: color: red;
  2. En formato hexadecimal: color: #ff0000;
  3. En formato RGB: color: rgb(255, 0, 0);
  4. En formato HSL: color: hsl(0, 100%, 50%);
  5. En formato HWB: color: hwb(0 0% 0%);
  6. En formato Lab: color: lab(53.24 80.09 67.20);
  7. En formato LCH: color: lch(53.24 80.09 40.00);
  8. En formato sRGB: color: srgb(255 0 0);
  9. En formato Display P3: color: display-p3(1 0 0);
  10. En formato color() con espacio de color: color(display-p3 1 0 0);
  11. O utilizando el propio selector de color.

Box Model

El modelo de caja de CSS es un concepto fundamental que describe cómo se representan los elementos HTML en la página web.
Cada elemento se representa como una caja rectangular que consta de cuatro áreas: el contenido, el relleno (padding), el borde (border) y el margen (margin).
El modelo de caja de CSS
Block_and_inline_layout

Estas propiedades de pueden definir usando las palabras: padding, margin, border para añadir espacio al rededor de los elementos,
sin embargo también se puede añadir espacio a un sólo lado añadiendo la palabra left, right, top o bottom después de la propiedad, por ejemplo: padding-left, margin-top etc.

Es importante saber que existen dos modelos el estándar y el modelo de caja alternativo, el estándar es el que se usa por defecto y el modelo de caja alternativo se activa usando la propiedad box-sizing: border-box;
La diferencia es que en el modelo estándar el tamaño total de un elemento se calcula sumando el tamaño del contenido, el relleno, el borde y el margen, mientras que en el modelo de caja alternativo el tamaño total de un elemento se calcula sólo con el tamaño del contenido y el borde,
es decir, el relleno y el margen no afectan al tamaño total del elemento lo cuál lo hace más predecible.
